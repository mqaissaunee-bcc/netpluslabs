Network+ Lab Companion

A study companion for all 15 hands-on labs in the NDG Network+ Lab Series. Each page has a plain-language overview, a command walkthrough with every flag explained, a reference table, a "where people get stuck" guide, CompTIA Network+ (N10-009) exam notes, self-check questions, a printable cheat sheet, and an evidence checklist for your screenshots.

Lab 01D1OSI Model and Encapsulation ConceptsWatch real traffic move through the OSI layers in Wireshark — frames, packets, segments, and the headers each layer adds. Lab 02D1IPv4 AddressingConfigure and verify IPv4 — DHCP and static — on both Windows and Linux, then prove connectivity with the right test commands. Lab 03D1IPv6 AddressingConfigure DHCPv6 and static IPv6 on a host, then verify with IPv6-aware test commands. Learn where the 128-bit address splits and how to compress it. Lab 04D2Understanding Network and Port Address TranslationConfigure SNAT, DNAT, and 1-to-1 NAT on a VyOS edge router — the mechanism that lets private hosts reach the Internet and exposes internal services. Lab 05D1Cloud Concepts and VirtualizationInstall a Type-2 hypervisor (Hyper-V), build a VM, install a guest OS, and use snapshots — the hands-on foundation under every cloud concept. Lab 06D2Routing TechnologiesRead a routing table, configure static and default routes on VyOS routers, and set jumbo frames — the fundamentals of how routers move packets between networks. Lab 07D2Routing ProtocolsConfigure and verify RIP, OSPF (v2/v3), and BGP on VyOS routers — the dynamic protocols that let routers learn routes from each other automatically. Lab 08D2Ethernet Switching TechnologiesConfigure a managed switch: hostname/banner/passwords, port security, SSH/Telnet remote management, VLANs and trunking, and link aggregation (LACP). Lab 09D2Controlling Traffic and Creating ACLsBuild a router firewall and write static and dynamic Access Control Lists to permit and deny traffic by source, destination, and direction. Lab 10D3Network AvailabilityKeep a network observable and in sync: configure NTP for time, SNMP for monitoring, and syslog for centralized logging. Lab 11D3Network Device Backup and RestoreSet up a TFTP server, back up a router's configuration to it, then restore it — the routine that saves you when a device fails or a change goes wrong. Lab 12D1D3Remote Access MethodsStand up a VPN server on pfSense, create a user, connect a client, and use SSH — the secure ways to reach a network and its devices from outside. Lab 13D4AAA AuthenticationConfigure pfSense as a RADIUS server, create user accounts, and authenticate remote VPN users against it — centralized Authentication, Authorization, and Accounting. Lab 14D5Using Appropriate Networking Commands and ToolsBuild fluency with the everyday diagnostic commands — ipconfig/ifconfig, ping, tracert, arp, netstat — and know which one answers which question. Lab 15D5General Network TroubleshootingDiagnose DNS with nslookup, read host routing with route print, inspect sessions with netstat, and automate checks with PowerShell — plus the CompTIA troubleshooting method.
