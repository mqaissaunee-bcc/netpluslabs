# Network+ Lab Companion

Student-facing companion pages for the **NDG Network+ Lab Series** — aligned to **CompTIA Network+ (N10-009)**.

## What's here
- `index.html` — the index / landing page (sortable by lab number or exam domain). **Start here.**
- `netplus_lab01.html` … `netplus_lab15.html` — one companion page per lab.

## Features (every page)
- Plain-language overview of what each lab is really teaching
- Command walkthrough with every flag explained + copy-to-clipboard buttons
- Reference tables (commands, ports, protocols) and a "where people get stuck" guide
- CompTIA Network+ (N10-009) exam-relevance notes mapped to the stated objectives
- Self-check Q&A, a printable cheat sheet, and an evidence checklist for screenshots
- Light/dark toggle, text-size controls, print support, progress tracking (localStorage)
- Single-file, offline-capable, CSP-safe — embeds cleanly in Canvas

## Hosting on GitHub Pages
1. Create a new repository and upload all `.html` files (and this README).
2. Settings → Pages → deploy from the `main` branch, root folder.
3. The landing page is served at the repo root URL (`index.html` is the default).

> The companion is a study aid. Always follow your official NDG lab document for graded steps.
