Overview — what this lab is really teaching

IPv4's ~4 billion addresses ran out. IPv6 is 128 bits — about 340 undecillion addresses — written as eight hex groups, e.g. 2001:050A:9E52:0D65:0000:000A:1234:CEF2. There's no subnet mask; the prefix length (usually /64) marks the network portion. The first 64 bits are the network, the last 64 the host.

You configure a host for IPv6 two ways — DHCPv6 (automatic) and static — then verify with IPv6-aware commands. pfSense provides the DHCPv6 and DNS services; WinOS is the client.

Compression rules you must knowDrop leading zeros in each group (00A → A), and replace one run of all-zero groups with ::. You may use :: only once per address.
Address types at a glanceLink-local (fe80::/10) is auto-configured on every IPv6 interface and used on the local link only. Global unicast (2000::/3) is the routable, Internet-facing kind.

Task 1.2 - Testing DHCPv6

1 From Windows Command Prompt, type ipconfig/release6, and then press Enter. Type ipconfig/all. Notice that the IPv6 global unicast address is gone. It has been released back to the DHCPv6 server pool in our network.

2 To request a new lease of IPv6 address configuration from the DHCPv6 server from Windows Command Prompt, type ipconfig/renew6, and then press Enter. After a few seconds, an IPv6 global unicast address appears.

3 From Windows Command Prompt, type ipconfig/all to view the full IP address configuration leased from the DHCPv6 server. Notice that the same IPv6 address was leased from the DHCPv6 server. The only difference is the time the lease was obtained. DHCPv6 will try to allocate the same IP address to the host machine requesting it.

IPv6 reference

PrefixTypeMeaning
2000::/3Global unicastRoutable, Internet-facing (like a public IPv4)
fe80::/10Link-localAuto-configured, local link only, never routed
fc00::/7Unique local (ULA)Private, site-internal (like RFC 1918)
ff00::/8MulticastOne-to-many; replaces IPv4 broadcast
::1/128LoopbackEquivalent of 127.0.0.1
::/0Default routeAll destinations
Prefix length
The IPv6 equivalent of a subnet mask; /64 = first 64 bits are the network.
SLAAC
Stateless Address Autoconfiguration — a host builds its own address from the router's advertised prefix, no DHCP needed.
EUI-64
A way to derive the 64-bit host portion from the interface MAC address.
Zone ID
The %12-style suffix on a link-local address identifying which interface it belongs to.

Where people get stuck

SymptomLikely causeFix
Only a fe80:: address appearsNo DHCPv6/RA received — only link-local auto-configuredConfirm pfSense DHCPv6 is enabled; link-local alone can't reach other subnets.
Ping to IPv6 gateway failsWrong prefix length or gatewayRe-check the prefix (usually /64) and the gateway address.
:: used twice in an addressInvalid compression:: may appear only once; expand one of the zero runs back to full groups.
Pinging link-local fails without zoneWindows needs the zone indexAppend the zone ID, e.g. ping fe80::1%12.

Exam relevance (N10-009)

  • Compress and expand IPv6 addresses correctly — a guaranteed exam skill.
  • Recognize link-local (fe80::), global (2000::/3), ULA (fc00::/7), loopback (::1).
  • Know /64 as the standard prefix and that IPv6 uses prefix length, not a dotted mask.
  • Know SLAAC vs DHCPv6 as the two autoconfig paths, and that multicast replaces broadcast in IPv6.

Check yourself

1. Compress 2001:0DB8:0000:0000:0000:00A1:0000:0001.

2001:db8::a1:0:1. Leading zeros dropped; the single longest zero run collapsed to ::.

2. A Windows host has only an fe80:: address. What's missing?

A global or ULA address — it got no DHCPv6 lease or Router Advertisement, so only the auto link-local exists. It can't leave the local link.

3. What replaces IPv4 broadcast in IPv6?

Multicast (ff00::/8). IPv6 has no broadcast at all.

4. What does /64 tell you?

The first 64 bits are the network/subnet prefix; the last 64 are the host (interface) ID.
