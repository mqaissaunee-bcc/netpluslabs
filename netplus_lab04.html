Overview — what this lab is really teaching

Private addresses (RFC 1918) can't appear on the Internet. NAT rewrites the addresses in packet headers at the edge router so private hosts can communicate with the outside world and vice-versa. You configure three flavors on a VyOS edge router:

  • SNAT (Source NAT) — rewrites the source address of outbound traffic so many inside hosts share one public address. With port tracking this is PAT (what home routers do).
  • DNAT (Destination NAT) — rewrites the destination of inbound traffic so an outside user reaching your public IP lands on a specific internal server (port forwarding).
  • 1-to-1 NAT — a fixed, bidirectional mapping between one public and one private address.
SNAT vs DNAT directionSNAT fixes who it's from on the way out. DNAT fixes who it's for on the way in. Keep the direction straight and the rest follows.

Source NAT (SNAT)

1Translate outbound traffic to the outside address

set nat source rule 10 description 'SNAT inside to outside'
set nat source rule 10 outbound-interface eth1

Destination NAT (DNAT)

1Forward inbound traffic to an internal server

set nat destination rule 20 description 'DNAT to internal server'
set nat destination rule 20 inbound-interface eth1
set nat destination rule 20 protocol tcp
set nat destination rule 20 destination port 80
set nat destination rule 20 translation address 192.168.10.50
commit ; save

Now an outside client hitting the router's public IP on port 80 is sent to the internal web server. 📷 screenshot for your report

Task 4 - Source NAT (SNAT)

Task 4.1 - Configure SNAT

1 In the Edge (vyos) device console prompt, type configure to enter configuration mode.

2 To configure SNAT, source rules are created and applied as follows: i. #set nat source rule 10 description 'SNAT' (Describe NAT purpose) ii. #set nat source rule 10 outbound-interface 'eth1' (Specify outbound interface) iii. #set nat source rule 10 source address '192.168.10.0/24' (Translate only traffic from private network 192.168.10.0/24) iv. #set nat source rule 10 translation address 'masquerade' (Use and overload IP address on outbound interface eth1 which is 168.50.80.1)

3 Enter the bolded commands on Edge. Press Enter after each line.

4 Type commit to accept the configurations you just made, and then type save to save the configuration.

5 Type exit to leave configuration mode.

NAT reference

TypeDirectionWhat it rewritesTypical use
SNAT / PATOutboundSource IP (+ port for PAT)Many private hosts share one public IP
DNATInboundDestination IP/portPort-forward to an internal server
1-to-1 (static)BothFull IP mappingDedicated public IP for one host
PAT (overload)
Port Address Translation — SNAT that also tracks source ports so thousands of sessions share one address. This is what home routers do.
masquerade
VyOS keyword for 'use the outbound interface's address' — the usual SNAT choice.
Inside local / global
The private vs translated public view of the inside host's address.
Why NAT exists
Conserves scarce IPv4 public addresses and hides internal addressing from the outside.

Exam relevance (N10-009)

  • Distinguish SNAT, DNAT/port forwarding, 1-to-1 (static) NAT, and PAT/overload — core objective 2.1 content.
  • Know why NAT exists: IPv4 conservation and address hiding.
  • Recognize port forwarding as a DNAT use case (exposing an internal service).
  • Understand that PAT lets many hosts share one public IP by tracking ports.

Check yourself

1. Three hundred office PCs reach the Internet through one public IP. Which NAT?

PAT (overloaded SNAT) — it tracks source ports so many private hosts multiplex one public address.

2. You want outside users to reach an internal web server. Which NAT, and in which direction?

DNAT (destination NAT / port forwarding) on inbound traffic — it rewrites the destination to the server's private IP.

3. On VyOS you built a rule but nothing changed. Why?

You didn't commit. VyOS stages changes and only applies them on commit; follow with save to persist.

4. What's the difference between 1-to-1 NAT and DNAT?

1-to-1 is a fixed, bidirectional full-address mapping; DNAT typically rewrites destination for specific inbound ports (port forwarding).
