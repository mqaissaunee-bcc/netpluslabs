Overview — what this lab is really teaching

AAA is the framework behind controlled access: Authentication (who are you?), Authorization (what are you allowed to do?), and Accounting (what did you do?). Centralizing AAA means one place to manage users instead of local accounts on every device.

You load a VPN config into pfSense, configure pfSense as a RADIUS server, create user accounts, test them, and then authenticate remote VPN users against RADIUS — so the VPN checks credentials centrally instead of per-device.

RADIUS vs TACACS+ — the exam's favorite comparisonRADIUS (UDP 1812/1813) encrypts only the password and combines authn+authz — common for network access/VPN/Wi-Fi. TACACS+ (TCP 49) encrypts the whole payload and separates authn/authz/acct — favored for device administration.

AAA reference

RADIUSTACACS+
Transport / portUDP 1812/1813TCP 49
EncryptsPassword onlyEntire payload
AAA separationCombines authn + authzSeparates authn / authz / acct
Typical useNetwork access, VPN, Wi-Fi (802.1X)Device administration (router/switch CLI)
OriginOpen standardCisco (widely supported)
Authentication
Proving identity — password, certificate, token, biometric.
Authorization
Determining what an authenticated identity may do.
Accounting
Recording what was done — sessions, commands, duration — for audit.
802.1X
Port-based network access control that uses a RADIUS server to authenticate devices before granting network access.
MFA
Multi-factor authentication — combining two+ of: something you know / have / are.
Shared secret
The key a RADIUS client and server use to trust each other.

Exam relevance (N10-009)

  • Define Authentication, Authorization, Accounting precisely — a guaranteed objective-4.1 item.
  • Compare RADIUS (UDP 1812/1813, password-only encryption, combines authn+authz) vs TACACS+ (TCP 49, full-payload encryption, separates AAA).
  • Know 802.1X uses RADIUS for port-based access control.
  • Recognize MFA and centralized identity as core security concepts.

Check yourself

1. Name the three A's and what each answers.

Authentication (who are you?), Authorization (what may you do?), Accounting (what did you do?).

2. You're securing CLI access to routers/switches and want full-payload encryption and command-level control. RADIUS or TACACS+?

TACACS+ — it encrypts the entire payload and separates authorization, making it ideal for device administration.

3. What ports does RADIUS use?

UDP 1812 (authentication) and UDP 1813 (accounting). Older deployments used 1645/1646.

4. How does 802.1X use RADIUS?

A switch/AP (authenticator) forwards a device's credentials to the RADIUS server, which decides whether to grant network access.
