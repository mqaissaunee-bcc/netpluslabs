Overview — what this lab is really teaching

Static routes don't scale — in a big network you can't hand-maintain every path. Dynamic routing protocols let routers advertise what they know and learn from neighbors, adapting automatically when links change. You configure the three the exam cares about, on VyOS:

  • RIP — a simple distance-vector IGP that counts hops (max 15). Easy, small-scale, dated.
  • OSPF — a link-state IGP that builds a full map and picks routes by cost. The workhorse of enterprise interior routing. You do both OSPFv2 (IPv4) and OSPFv3 (IPv6).
  • BGP — the path-vector protocol that routes between autonomous systems. It runs the Internet. You configure it for both IPv4 and IPv6.
IGP vs EGPRIP and OSPF are interior gateway protocols — inside one organization. BGP is the exterior protocol — between organizations/ISPs (between autonomous systems).

Protocol reference

ProtocolTypeMetricScopeRoute code
RIP (v2)Distance-vector IGPHop count (max 15)Small interiorR
OSPFLink-state IGPCost (bandwidth)Enterprise interiorO
EIGRPAdvanced DV IGP (Cisco)CompositeEnterprise interiorD
BGPPath-vector EGPPath attributesBetween AS / InternetB
Autonomous System (AS)
A network under one administrative control, identified by an AS number — the unit BGP routes between.
Convergence
How quickly all routers agree on the topology after a change; link-state (OSPF) converges faster than distance-vector (RIP).
Router ID
A 32-bit ID that uniquely names a router within OSPF/BGP.
Area 0 (backbone)
OSPF's core area that all other areas connect to.
eBGP vs iBGP
External BGP peers sit in different AS numbers; internal BGP peers share the same AS.

Where people get stuck

SymptomLikely causeFix
OSPF neighbors won't formMismatched area, subnet, or MTU between the two interfacesBoth sides need the same area and a common subnet; check show ip ospf neighbor for the stuck state.
RIP routes missingNetwork not advertised, or beyond 15 hopsAdd every connected network with set protocols rip network; RIP drops anything past 15 hops.
BGP stays in Idle/ActiveWrong remote-as, unreachable peer, or missing multihopConfirm the neighbor IP is reachable and the remote-as matches the peer's actual AS.
Routes learned but no reachabilityAdvertised the wrong networkAdvertise the networks you actually want reachable; verify with show ip route <proto>.

Exam relevance (N10-009)

  • Classify protocols: RIP = distance-vector, OSPF = link-state, BGP = path-vector; IGP vs EGP.
  • Know each protocol's metric: RIP hop count, OSPF cost, BGP path attributes.
  • Know BGP routes between autonomous systems and runs the Internet.
  • Understand convergence and why link-state converges faster than distance-vector.

Check yourself

1. Which routing protocol connects two different ISPs?

BGP — the exterior/path-vector protocol that routes between autonomous systems.

2. Your network is 18 router-hops wide. Why is RIP a bad fit?

RIP's maximum is 15 hops; anything beyond is considered unreachable, so it can't route across the whole network.

3. What metric does OSPF use to choose a path?

Cost, derived from link bandwidth — lower cost is preferred.

4. eBGP vs iBGP — what's the distinguishing factor?

Whether the peers are in different AS numbers (eBGP) or the same AS (iBGP).
